### 横切结论(适用于全部训练提案)

**C1|0.86 地板改写期望值结构(最重要)。** final selection 取 2 份历史提交,53414820 的 0.86 在账 ⟹ 地板 = 0.86,不是 run-011 的 0.85。**任何挑战者打出 0.85 或 0.86 对最终名次的贡献严格 = 0**;全部训练提案的"中心情形"(+0.5~1.0pp → 显示 0.85-0.86)都是无效奖。RL 花费买的不是"中心 +0.8pp",而是**一张 P≈15-25% 的右尾彩票(≥0.865 真分)+ 情报**。这必须明示给用户做解锁决策,否则就是用无效奖的中心值给彩票定价。附带:终选若锁 {run-011, 挑战者} 而不含 kienngx-0.86,等于白丢 1pp(05 的兜底条款写错了)。需自查规则:以他人公开 adapter 作最终提交的合规性(它已被接受打分,LB 层面无碍;奖金层面有原创性条款风险)。

**C2|17% 是本战役被引用最多、证据最薄的数字。** n=12、已训题、CI 2-48%、cap 2000。且有一个被所有提案回避的强反例:run-011 在 ~116-135 条 crypt solver trace 上训练后,holdout crypt 贪心 = **0/107**——crypt 的 train→holdout 迁移历史记录是零。"这次不同"的全部论证压在"on-policy 自采 trace ≠ 外生 trace"一个机制区分上,该区分对**已训题的复现**有证据(probe80),对**跨题泛化**没有任何证据。M0/Phase-0 类的 $4-30 直测闸是唯一救赎,必须在任何大额采购前执行,且必须包含 holdout 侧(非已训)题的 pass@k。

**C3|世界 B 已到货,提案没更新。** V3 的数据在各提案定稿后才解码出来,不怪提案人;但红队判决以最新数据为准:0.7 折扣下限锁死,01 中心 +1.0→实际 +0.5~0.7、02 中心 +0.8→+0.5~0.6、05 中心 +0.8→+0.5 左右。叠加 C1,中心情形价值≈0,决策权重应全部放在:① 闸门是否便宜且早;② 右尾概率是否被诚实定价。

## 1. 提案 01 · GRPO/RLVR —— 判决:**FIX**

**好的部分(承认)**:死亡名单对表干净(死区一题不进池、零外生 trace、不动格式);Phase-0 $20-30 先测 f_signal 再发车;止损三档预登记;反遗忘五件套是五份里最完整的;"锚题零方差组免费蒸发、遗忘时自动产生纠正梯度"的机制论证正确。

**攻击点(修了才放行)**:
1. **战略位置错误:首发主攻 vs 条件武器。** $280/$330 是 02 号 RFT($40)的 7 倍,吃**同一个 64 题池**;05 的交并分析(GRPO 与 RFT 重叠 >80%,串行升级)是对的。GRPO 的独有价值只在"覆盖高但 RFT 翻转失败"的残余上,这个条件 06-13 G2 才能判定。先烧 $145 跑 Leg-1 再看 RFT 能不能用 $7 训练费解决同一池,顺序颠倒。
2. **中心 +1.0pp / P(0.865)=0.25 在 world-B 证据下高估。** 转化链 ①覆盖 30-45% 的"复利"假设(policy 改进使命中率逐 pass 上升)无任何实测;②覆盖→翻转 60-80% 是 C 级;④迁移折扣 0.5-0.8 按 V3 应取下限。重算中心 ≈ +0.4~0.7pp、P(0.865)≈0.12-0.18。对照 run-012 预登记高估前科,0.25 不诚实。
3. **wall-clock 风险被低估。** 768 rollouts/步,按挖矿吞吐(2000 rollouts/小时级)外推是 23-45 min/步,不是 5-20 min;60 步 = 23-45h,D2 内跑完 Leg-1 + 当晚提交的排程一断,$145 沉没且无 LB 读数。预登记的降档规则(P=48/G=12)好,但降档后的覆盖率假设同步下修没有写出新中心值。
4. **eq 签名类 30-50 题入训练池缺直测**(V5):oracle-fail 题,死区近邻,最近的 A 级测量 1.8%。必须在 Phase-0 顺带 K8 直测后才许入池,否则就是变相死区采样(小剂量)。
5. 小项:"crypt 收口是 RL 独有杠杆、SFT 根本表达不了"——不成立,02 用"只收 ≤3k tok 短正样本"同样表达收口压力;不许用这句当 GRPO 相对 RFT 的差异化卖点。锚/巩固巡逻采样 ~$0.64/步×60=$38,与每 10 步 $0.10 贪心探针冗余,可砍一半。

**FIX 清单**:① 降级为 05 框架下 G2 分支的条件武器(覆盖高 + RFT 翻转低才解锁,即原 R3 激进档),Phase-0 与 M0 合并先行;② 删 Leg-2 预承诺;③ 中心改 +0.4~0.7pp、P(0.865) 改 0.12-0.18,并按 C1 注明中心情形最终价值为零;④ eq 签名类先测后入;⑤ wall-clock 按 25-45 min/步重排 D2-D3 时刻表并给降档后的新预测。

## 2. 提案 02 · RFT / Expert Iteration —— 判决:**FIX**(修账后即为主攻,最接近 GO)

**好的部分**:greedy 对齐论证(NLL 直接抬 argmax)成立;$/题 最低、证伪最早($21/$25 两道闸都在首次提交前);正样本卫生(短 trace、剔截断、≤2 条/题、剔 `}` truth)同时就是收口治疗;self-distill 锚 + 62% 锚占比是对 E4 事故最对症的设计;弹药对 01/03 全复用;死亡名单对表全部成立——crypt 腿与 crypt-synth 死刑的区分("模型自采 vs 外生 trace")是五份里论证最扎实的一处,且有便宜闸兜底。

**攻击点(修了才放行)**:
1. **crypt 可采率中心 25% 高估**(C2):17% 是已训题 + n=12 + cap2000;"K 翻倍 ×1.5、cap 放开 ×1.5"两个乘数都是拍的——尤其 cap 乘数:两条营救成功 trace 只有 913-1628 字符,cap 从 2000 放到 7680 主要增产的是截断垃圾,不是命中。crypt 中心应记 +1~2 题(不是 +3~4),或先花 ~$1 对 holdout 26 题 K8 直测后再记账。
2. **"holdout 同类泛化率 50-60%"应降级为 C 级并下修。** 所引 probe80 证据(已训锚题贪心复现 80-100%)是**同题复现**,不是跨题泛化;crypt 的历史跨题迁移记录是 0(C2 反例)。bit 的"近失=执行模式同构"论证相对可信,但也无直测。建议:bit 泛化 40-60%、crypt 泛化 20-40% 分开记,合计中心从 +13~15 题下修到 +8~12 题(world-B 折扣后 ≈ +0.4~0.55pp LB)。
3. **P4 LB#1 中心 0.855 重蹈 run-012 套路**(V4)。改 0.850-0.853;且按 C1 补一行:LB#1 ≤0.86 时本路对最终名次贡献为零,继续投入的理由只能是"r2/r3 还有右尾"。
4. **算术矛盾**:round-1 "~1400 例 ÷ 64 ≈ 22 步、1 epoch 不重复"与"正样本占 37%(≈520 槽位)但去重后唯一正样本只有 ~150-250 条"冲突——正样本实际要重复 2-3 遍,要么承认 2-3 epoch 等效(遗忘压力相应上调),要么砍步数。修正后给真实步数。
5. 排程:D0 晚 harvest 在解锁前不可执行(纪律),全链从 D1 起算;识别 pass 与 05 的 M0 应合并成同一笔钱,别两家各买一次。

**FIX 清单**:①②③④⑤ 如上;另外 P2 闸建议加一条 holdout 侧子闸(holdout 26 crypt + 11 bit 的 K8 直测,~$1.5,与 05 的 M0 共用),使"已训题可采 ≠ holdout 可采"这个 C2 风险在 $25 内有直接读数。

## 3. 提案 03 · DPO 族(RPO 混合)—— 判决:**FIX**(只许以附属臂形态存活)

**好的部分**:自我判决诚实("纯 DPO/SimPO/KTO 不单独成路"),likelihood displacement、greedy 错位、off-policy 三条否决理由全部引证正确;主动纠偏"run012_holdout_decode 是 holdout 题禁止入训"是五份里唯一抓住这个污染点的;P2(chosen logprob 连降 3 步即关 DPO 项)是displacement 的正确熔断;LR 5e-6/<20 步/对照臂设计都对。

**攻击点(修了才放行)**:
1. **删掉"独立 $19-22 全程"选项。** 独立跑 = 重复支付与 02 完全相同的筛查+采样费,吃同一池;本提案存在的唯一合法形态是 02 的附加损失($6-9 边际),且 02 的 P2/P3 闸若证伪则本提案自动作废——这个依赖关系要写成硬条款,不是"衔接说明"。
2. **归因判据在 LB 显示粒度下失效。** 预期 DPO margin 边际只有 +0.2~0.3pp(自报,C 级、无量化文献锚),LB 粒度 0.01:RPO 臂 vs RFT-only 臂大概率同显示 0.85/0.86,P5"RPO>RFT"在 LB 上读不出来还烧 2 配额。修法:归因主指标改为 holdout 预登记猎物名单逐题对比(免费),LB 只做单臂(取 holdout 赢家),省 1 配额。
3. **长度混杂未入账**:crypt pair 的 rejected 是 7680 截断 trace(截到 3072 仍 ≈3 倍于 chosen),unnormalized margin 会被长度差主导。方向上恰好是要的"压写长",但这意味着 margin 学到的可能只是"短 > 长"而非"对 > 错"——与"定向压制现任错误 argmax"的机制声明不符,P5 归因要把这个混杂写进去(若 RPO 边际全部来自 crypt 收口而 bit 无边际,即为长度效应实锤)。
4. 小项:"DPO 自带 β-KL 锚"只约束 pair 分布上的偏离,对 pair 外的锚类(cipher/gravity/numeral/unit)无保护——反遗忘不能记这一层功劳,实际护栏只有 replay 交替步 + 熔断(已有,够用,但表述要改)。

**FIX 清单**:① 改为 02 的硬依赖附属臂,预算只保留 $6-9 + 对照评测;② P5 归因主战场移到 holdout 逐题;③ 长度混杂写入 P5 读法;④ 反遗忘表述纠正。
