# bit 规则先验反学习 + 平局裁决实测(2026-06-12)

代码:`rl/bit_prior.py`(单版本);全量日志:`rl/bit_prior_full.log`。
数据:train_cat.csv 1602 道 bit(剔除 holdout 后 1492 道作先验学习),holdout 110 道
(id 取自 run012_holdout_decode.jsonl,模型基线 91/110)。

## 结论一句话

**"92.8% 信息论上限"被证伪,holdout oracle 实测 110/110,相对模型基线净增 +19,
打破 0。** 旧上限是循环论证:用我们自己解题器的窄规则族测"歧义",窄族覆盖不了的题
被误判成"同例子多输出、不可消歧"。换对规则族后,真歧义几乎不存在。

## 出题器真实规则族(真值监督下逆向)

基原子(24 个):`id, rl1-7(循环左转), sl1-7(左移补零), sr1-7(右移补零), nt(取反), rv(反序)`。

| 层级 | 结构 | train canonical 占比(粗签名 top) |
|---|---|---|
| T1 unary | 深度≤2 复合原子 | `rl` 86, `sr` 35, `sl` 16 |
| T2 pair | 8 种布尔二元(XOR/AND/OR/ANDN/ORN/XNOR/NAND/NOR)× 复合原子 | `XOR(sl,sr)` 360(最大单族), `OR(rl,sr)` 74, `XOR(rl,sl)` 67, `AND(rl,nt.sl)` 63 … |
| T3 nested | `op2(op1(a,b),c)` 三原子嵌套 | `XOR(ORN(sr,rl),sl)` 118, `OR(XNOR(rl,sl),sr)` 47, `XOR(NOR(rl,sr),rl)` 44 |
| T4 maj/mux | MAJ/MUX 及取反 | `MAJ(rl,sl,sr)` 141, `MUX(sl;sr,rl)` 55, `NMUX(sr;sl,sr)` 13 |
| T5 gf3 | 固定三元函数 `F[11010110](rl_a,sl_b,sr_c)` ≡ `a ? (b XOR c) : (¬b OR c)` | 49(零候选题 fallback,50/50 全命中) |

我们旧解题器(legacy 逐列 + EV 固定梯子)只覆盖 T1/T2 的"单层"子集——这正是
模型 19 道丢分的全部来源:**16/19 道在扩展族下根本无歧义(npred=1),纯粹是族外**;
只有 5 道有多候选,且全部被裁决拿下。

## 实测数字

| 指标 | train(1492,去 holdout) | holdout(110) |
|---|---|---|
| 覆盖率(真值在候选集) | 1489/1492 = 99.8% | **110/110 = 100%** |
| 歧义题(多预测) | 363(全部 covered) | 26(全部 covered) |
| 先验裁决正确 | in-sample 99.1%,**5-fold 98.9%** | **110/110** |
| 最简规则裁决(无先验) | 97.9% | 109/110 |
| 相对模型基线 91/110 | — | **净增 +19;修复 19,打破 0** |

- 平局裁决 = 按 (精确签名计数, 0.1×粗签名计数, −复杂度) 排序,先验从 train(已剔
  holdout id,无泄漏)学得;5-fold 与 in-sample 仅差 0.2pp,无过拟合。
- 连"奥卡姆最简"裁决都 109/110:**歧义是伪问题,族覆盖才是真瓶颈**。
- 残差:train 仅 3/1492(0.2%)未覆盖(955e8713 / ccf02dee / f507b7f1,各有 1 个
  一致候选但 query 预测错——更深规则 alias,暂未追)。

## LB 换算与外部互证

+19/110 = bit 队列 +17.3pp;bit ≈ LB 1/7 权重 → **LB 上限 ≈ +2.5pp**(R=1 时),
约等于 0.85→0.87 的全部缺口。与"30 队实打 0.87、别人 bit 98-99%"情报互证:别人
就是用了正确的规则先验,没有撞"歧义墙"。

## 诚实风险声明(oracle ≠ LB)

- run-012 教训在案:bit-EV 全局断言格式 +114 oracle 离线为真,但模型复现 0/30
  (PATHS.md L53)。**+19 oracle 要兑现成 LB,trace 格式是主风险。**
- 可行通路:扩展族的每条规则都能投影成逐位形式
  `out_i = f(in_{(i+a)%8}, in_{(i+b)%8}, in_{(i+c)%8})`(移位题边界位为常数),
  与模型已稳定复现(R≈0.95)的 legacy 逐列匹配格式同构——发射"三操作数逐列表"
  而非全局断言,绕开 run-006/007/008 与 bit-EV 的死亡格式。
